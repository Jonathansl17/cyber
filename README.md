# Cyber Security

Guía de estudio del roadmap de Cyber Security de roadmap.sh, solo con los temas que no están marcados como skipped. El roadmap completo con los skipped marcados está en [`roadmap-cyber-security.pdf`](roadmap-cyber-security.pdf).

Cada tema tiene conceptos con analogías y ejemplos, una sección de recursos (videos, lectura y labs de práctica) y un cuadro resumen al final.

| # | Tema | Qué cubre |
|---|------|-----------|
| 01 | [Fundamentos de IT](01-fundamentos-it/) | Troubleshooting independiente del SO, suites de productividad, panorama de redes |
| 02 | [Linux](02-linux/) | GUI y CLI, permisos, troubleshooting, comandos comunes |
| 03 | [Fundamentos de redes](03-fundamentos-de-redes/) | Modelo OSI, topologías, LAN/WAN/MAN/WLAN, NAS y SAN |
| 04 | [Direccionamiento IP](04-direccionamiento-ip/) | Subnetting, IP pública y privada, CIDR, gateway, VLAN, DMZ, ARP, NAT, DHCP, DNS, NTP, IPAM |
| 05 | [Protocolos y puertos](05-protocolos-y-puertos/) | Protocolos y puertos comunes, SSH, RDP, FTP, HTTP(S), TLS, handshakes |
| 06 | [Virtualización](06-virtualizacion/) | Hipervisores, host y guest, VMware, VirtualBox, ESXi, Proxmox, aislamiento |
| 07 | [Herramientas de red](07-herramientas-de-red/) | ping, dig, netstat, nmap, tcpdump, iptables, sniffers y analizadores |
| 08 | [Autenticación](08-autenticacion/) | AuthN vs AuthZ, MFA, Kerberos, RADIUS, LDAP, SSO, certificados |
